API REFERENCE

短链接

用 API Key 创建指向指定 HTTPS 地址的短链，并通过公开地址临时跳转。

POST/v1/short-links创建短链
短链归创建它的 API Key。公开访问 /s/{shortCode} 无需凭证；禁用、删除、到期或上层资源不可用时不会继续跳转。

请求参数

字段类型说明
namestring短链名称，1～64 字符
originalUrlstringHTTPS 目标，最多 2048 字符；仅允许白名单精确主机名
expiresAtdatetime带时区的未来绝对时刻；到达该时刻即过期

请求示例

HTTP · 复制示例
POST /v1/short-links
Authorization: ApiKey <完整密钥>
Content-Type: application/json

{
  "name": "秋季活动视频",
  "originalUrl": "https://www.douyin.com/video/123456",
  "expiresAt": "2030-01-01T16:00:00+08:00"
}

返回与管理

响应包含 shortCode、apiKeyId、名称、目标地址、状态和到期时刻。机器端还能查询、修改及删除本 Key 的短链；登录用户可在控制台按 Key 查看并管理。

目标检查只验证提交时的 HTTPS 协议和精确主机名，不保证目标页面内容合法或安全。短码由服务器生成，删除后也不复用。
