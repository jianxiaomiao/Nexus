## 页面归属与视觉

- 调用统计归当前 API Key 详情页，不增加侧栏一级入口。沿用现有返回链接、Key 名称与状态，以及右上角编辑、禁用/启用、删除操作。
- 详情页现有「密钥信息 / 短链接 / 调用统计」三个标签。「密钥信息」保留原字段和完整 Key 仅创建时显示的提示；「短链接」保留通往现有管理页的 Key 预选入口；「调用统计」读取当前 Key 的聚合数据。
- 沿用 [NEXUS_DESIGN_GUIDE.md](NEXUS_DESIGN_GUIDE.md) 的暖白纸面、浅鼠尾草绿导航、深墨绿正文、青绿色交互与少量金色品牌点缀。统计区域保持克制，避免把外部平台的蓝色仪表盘风格带入 Nexus。

## 数据与交互

- 统计只读取当前 Key 的 Usage 查询响应：`allTimeCount`、`periodCount`、`timeZone`、`periodStart`、`periodEndExclusive`、`dailyCounts`、`apiCounts`。
- 两张概览卡分别显示累计调用次数与选中时段调用次数；柱图按 `dailyCounts` 显示每日次数，纵轴从零开始。日期以返回时区展示，图中采用北京时间 UTC+8。
- 接口列表按 `apiCounts` 展示 `apiName`、`apiCode` 和 `count`；占比在前端用 `count / periodCount` 计算，`periodCount = 0` 时显示 0%。图中的六个接口对应当前 `ApiCode`，实际行数和顺序由响应决定。
- 时间选择提供后端已有的今天、昨天、近7天、近30天、本月、上月、自定义。视觉稿只画出常用选项；自定义时间以北京时间输入。接口区间采用左闭右开边界，显示给用户的结束日期须避免误读。
- 时段没有记录时，仍显示真实的累计次数；每日图表使用「该时段暂无调用记录」空状态，接口列表为空。Key 或 Application 禁用后，仍可查看此前记录。
- 当前聚合响应没有成功率、错误次数、耗时和最近调用明细，视觉稿不提供这些指标。图中「演示数据」标识仅用于评审，真实页面不显示。
- 手机端两张概览卡保持可读，接口表变为逐行列表；近30天图表在窄屏需要可横向浏览，不能把日期和柱子压到难以辨认。

## 验收状态

- 管理端 `GET /api/usage` 已改为查询参数；真实 JWT/HTTP/MySQL 测试验证禁用后可查看历史、日期边界、空日期和异常时间范围。前端浏览器测试验证三个标签、Bearer GET、筛选、空状态、重试与手机布局。
- 真实浏览器连接运行中的后端仍待开发者验收；完整 API Key 不得出现在统计页面、日志或复制操作中。
